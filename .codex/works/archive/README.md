# Archive

Bu klasör artık canonical olmayan fakat provenance veya eski araç karşılaştırmaları için korunması gereken salt-okunur dosyaları tutar.

- `title_relations/`: eski relation baseline ve inceleme öncesi/bozuk sürümler.
- `legacy_reports/`: güncel closure sonucu sayılmayan tarihsel raporlar.
- `merge_restore_backups/`: merge sonrası geri yükleme ve provenance doğrulaması için korunan snapshot raporları.

Arşiv dosyaları yeni kararların kaynağı olarak kullanılmaz. Bir araç arşiv girdisi okuyorsa bunu adında veya CLI açıklamasında açıkça belirtmelidir.
