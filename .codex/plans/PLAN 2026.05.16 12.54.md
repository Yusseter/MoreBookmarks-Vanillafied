# MPE Add 1 Tutarlılık Kontrol ve Onarım Planı

## Summary
MPE import sonrası düzeltmeleri tek seferlik manuel edit değil, raporlu iki aşamalı pipeline olarak ele alacağız: önce audit, sonra kullanıcı kararlarıyla kilitlenmiş onarım. `test_files` kullanılmayacak. Localization eksikleri otomatik üretilmeyecek; raporlanacak.

## Key Changes
- Yeni audit aracı: `works/tools/audit_mpe_add_1_consistency.py`.
- Yeni uygulama aracı: `works/tools/apply_mpe_add_1_consistency_fixes.py`.
- Karar tabloları:
  - `mpe_history_donor_map.csv`
  - `mpe_barony_alias_locator_map.csv`
  - `mpe_title_structure_fix_map.csv`
- Donor kaynak kuralı:
  - Current Yusseter’de title yorumlu/silinmiş olsa bile Levi kaynakta varsa donor geçerlidir.
  - `c_don_portage` donor olarak Levi `common/landed_titles`, Levi `history/titles`, Levi `history/provinces` üzerinden okunacak.

## Implementation Changes
- Localization audit:
  - MPE ile eklenen/taşınan tüm `b_`, `c_`, `d_` ve kullanılan `cn_*` keyleri kontrol edilecek.
  - Kaynak sırası: current, MPE, Levi.
  - Kaynakta bulunmayan localization üretilmeyecek; raporlanacak.
  - Bilinen eksikler: `b_khunzakh`, `c_majar`, `cn_iryston`.

- History donor fix:
  - Kullanıcının donor county listesi tabloya yazılacak.
  - Yazım düzeltmeleri kilitli:
    - `c_digora` -> `c_digoria`
    - `c_tapanda` -> `c_tapanta`
  - Target county title history ve target capital barony province history, verilen donor county’den alınacak.
  - Culture/religion sadece target county capital barony province’inde olacak.

- Landed title structure fix:
  - `c_besinada`, `c_majar`, `c_alania` donor’u Levi `c_don_portage`.
  - `b_targin` `c_ossetia` altına taşınacak.
  - `c_lazia` altındaki baronyler `c_avaria` altına taşınacak.
  - `c_perekop`, `c_khortytsia` ve benzer Levi kökenli county renkleri Levi’deki gibi kalacak; MPE rengiyle ezilmeyecek.
  - `c_kerch/c_cherson/c_korchev` için özel mapping uygulanacak:
    - Current `c_kerch` eski Levi `c_cherson` karşılığı olarak korunacak.
    - Current MPE `c_cherson` içindeki alias baronyler eski Levi barony keyleriyle değiştirilecek.
    - Comment formatı: `# Yusseter: MPE alias donor <old_mpe_id>`.

- Barony alias + locator donor mapping:
  - `b_gialta` yerine `b_yalta`: donor `13359`, target old ID `9837`.
  - `b_symbolon` yerine `b_yamboli`: donor `13360`, target old ID `9836`.
  - `b_phoros` yerine `b_mangup`: donor `13361`, target old ID `9835`.
  - `b_anapa` yerine `b_batacrim`: donor `12922`, target old ID `9838`.
  - `b_soldaia` yerine `b_sukdak`: donor `13362`, target old ID `9833`.
  - Altı `gfx/map/map_object_data` dosyasında donor locator block target old ID’ye kopyalanacak.
  - Superseded donor IDs landed_titles içinde aktif title association taşımayacak; audit bunlar hâlâ playable/title-required kalıyorsa blocker raporu verecek.

- History audit:
  - Target county title history var.
  - Target capital barony province history var.
  - Non-capital target barony province’lerinde culture/religion yok.
- Localization audit:
  - Eksikler raporlanır, otomatik doldurulmaz.

## Assumptions
- `test_files` sistemi kullanıcı tekrar söyleyene kadar kullanılmayacak.
- `c_don_portage` current dosyada yorumlu olsa da Levi kaynakta aktif olduğu için donor’dur.
- `c_digoria` ve `c_tapanta`, kullanıcıdaki `c_digora/c_tapanda` yazımlarının doğru karşılığıdır.
- Alias mappinglerinde eski Levi barony keyleri ve eski province ID’ler korunur; MPE ID’ler locator donor ve provenance kaydı olarak kullanılır.
