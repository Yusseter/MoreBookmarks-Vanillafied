**Doğu Title Rewrite Sistemi**

**Summary**
- Amaç: `title_relation_master_manuel_new.csv` içindeki eşleşmelere göre asli mod/doğu title id referanslarını bizim kullanılan title id’lere çevirmek.
- Rewrite yönü kesin: `mod_title_id -> source_title_id`. Örnek: `k_jin_china -> k_hedong`, `k_guangxi -> k_lingxi`, `k_guangnanxi -> k_lingxi`.
- `is_same_title_id = yes` olan mappingler rewrite edilmez; audit içinde `same_id_noop` olarak görünür.
- Kapsam: `common`, `history`, `events`, `decisions`, `map_data/geographical_regions` gibi oyun dosyaları. `localization`, `works`, manuel CSV’ler ve rapor çıktıları rewrite dışında kalır.
- Yorum satırları rewrite edilmez; aktif script kısmı `#` öncesi token bazlı işlenir.

**Implementation Changes**
- Yeni script önerisi: `works/tools/rewrite_east_title_ids.py`.
- Script varsayılan olarak dry-run/report üretir; `--write` verilmeden live/test dosyaları değiştirilmez.
- Mapping parser `&` satırlarını genişletir; `k_lingxi, k_guangxi & k_guangnanxi, no & no` iki atomik mapping olur.
- `(second)` suffix’i ayrı aksiyon türüdür; normal replace değil, clone isteği üretir.
- `(second)` için karar: mevcut mod title bloğu/satırı korunur, sadece block clone yapılır; block dışındaki referanslar otomatik clone edilmez, rapora düşer.
- Atomic rewrite yapılır; üretilen yeni token tekrar rewrite motorundan geçmez. Bu `c_fuzhou_jiangxi_china -> c_jianchang -> c_jianchang_1` gibi zincir bozulmalarını engeller.
- Token eşleşmesi tam title token olarak yapılır; `some_c_jianchang_flag` gibi birleşik identifier parçaları değiştirilmez.
- `common/landed_titles` ve `history/titles` için title block parser kullanılacak; block header rename/clone işlemleri brace-aware yapılacak.
- Eğer direct rewrite veya second clone aynı dosya/kapsamda duplicate title block yaratacaksa otomatik yazılmaz; `block_collision` olarak raporlanır.
- `test_files` karşılıkları live ile aynı çıktıdan yenilenir ve hash eşitliği doğrulanır.

**Reports**
- `east_title_rewrite_plan.csv`: genişletilmiş mapping tablosu; `source_title_id`, `mod_title_id_base`, `mapping_kind`, `is_same_title_id`, `is_second`, `is_amp_group`, `rewrite_action`.
- `east_title_rewrite_issues.csv`: sadece müdahale gerektiren durumlar; `status` kolonuna göre sıralı.
- `east_title_rewrite_info.csv`: bilgi amaçlı satırlar; örn. same-id noop, beklenen multi-map grupları, skipped comments.
- `east_title_full_mod_title_audit.csv`: `common/landed_titles` içindeki 17085 tanımlı title için durum raporu.
- Audit CSV kolonları: `title_id`, `tier`, `defined_file`, `line_no`, `relation_role`, `mapped_source_title_id`, `mapped_mod_title_id`, `rewrite_status`, `collision_status`, `chain_risk_status`, `notes`.
- Özel rapor statusları: `multi_mod_title_id_mapping`, `second_block_clone_mapping`, `rewrite_chain_collision_risk`, `block_collision_would_duplicate`, `second_reference_report_only`, `same_id_noop`.
