# Landed Title Pipeline Inputs

- `capital_decisions.csv`: seçilmiş landed-title capital kararları.
- `parent_decisions.csv`: seçilmiş landed-title parent kararları.

Bu dosyalar analiz çıktısı değildir. Araçlar tarafından okunabilirler ancak açık bir karar süreci olmadan otomatik olarak yeniden yazılmazlar.
