# County-Based Culture/Religion Overlay For Province History

## Summary

- `00_MB_PROVINCES.txt` normal province-history merge ile üretilecek, ama `culture` ve `religion` değerleri son aşamada county relation üzerinden override edilecek.
- Authoritative source: `F:\Storage\Codding\git\Crusader Kings III\Leviathonlx MoreBookmarks-Plus\BookmarksGit`.
- Mapping kaynağı: `title_relation_master_manuel_new.csv`; burada `source_title_id` bizim target/current county, `mod_title_id` asıl moddaki source county kabul edilecek.
- `common/landed_titles/00_landed_titles.txt` değiştirilmez; sadece okunur.

## Key Changes

- `implement_core_province_integration.ps1` içine county culture/religion overlay aşaması eklenecek.
- Yeni parametreler:
  - `-SourceModRoot`, default Leviathon repo path’i.
  - `-TitleRelationCsv`, default `title_relation_master_manuel_new.csv`.
  - `-SkipCountyCultureReligionOverlay`, gerektiğinde overlay’i kapatmak için.
- Yeni raporlar:
  - `works/analysis/generated/core_province_integration/county_culture_religion_overlay_report.csv`
  - `works/analysis/generated/core_province_integration/county_culture_religion_overlay_summary.md`

## Implementation Details

- Normal history merge önce mevcut mantıkla çalışacak: final candidate province block’ları source history’den alınıp final ID’ye rewrite edilecek.
- Sonra overlay şu akışla uygulanacak:
  - Relation CSV’den tüm mapped `c_ -> c_` satırları okunacak.
  - Target county’nin ilk direct `b_` title’ı target landed_titles içinden bulunacak.
  - Source county’nin ilk direct `b_` title’ı Leviathon landed_titles içinden bulunacak.
  - Source top barony province ID’sinin history block’undan yalnızca immediate `culture` / `religion` assignment’ları çıkarılacak.
  - Root seviyesindeki `culture` / `religion` target top province block’unda source değerleriyle değiştirilecek.
  - Source date block’larında bulunan `culture` / `religion` target block’a taşınacak; aynı tarih varsa sadece bu iki key override edilecek, diğer içerik korunacak.
  - `holding`, `special_building_slot`, `special_building`, development veya başka history effect’leri source’dan kopyalanmayacak.
- Missing policy:
  - Target county, target first barony, source county, source first barony veya source culture/religion bulunamazsa target block değiştirilmez.
  - Bu durum `blocker` olarak rapora düşer.
- Örnek kabul davranışı:
  - `c_hengzhou -> c_hengshan_china`
  - Target first barony: `b_hengyang_1`, province `8970`
  - Source first barony: `b_hengyang_hengzhou_china`, province `12004`
  - `12004` içindeki `culture/religion` ve ilgili dated culture/religion değişimleri `8970` block’una overlay edilir.
