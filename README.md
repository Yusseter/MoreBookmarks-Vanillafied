# More Bookmarks Vanillafied

An adaptation of [More Bookmarks+](https://github.com/Leviathonlx/MoreBookmarks-Plus) for Crusader Kings III that aims to preserve vanilla map projection and data identities while retaining the mod's expanded bookmarks and historical content. Maintained by [Yusseter](https://github.com/Yusseter).

## Scope

The project's goals are to:

- Retain the additional bookmarks and historical content provided by More Bookmarks+.
- Adapt More Bookmarks+ to the vanilla CK3 map projection.
- Preserve vanilla keys, province IDs, culture identifiers and other data identities wherever practical, while retaining More Bookmarks+ content.

## Development Status

This project is under active development and follows the upstream More Bookmarks+ project's ongoing CK3 1.20 updates. Compatibility can vary between revisions and bookmarks.

## Using The Source

The playable mod directory is [`BookmarksGit/`](BookmarksGit/). It includes the mod descriptor and the game data maintained by this project.

[`upstream-extras/`](upstream-extras/) retains upstream files that are outside the playable mod, at their original relative paths, to support subsequent merges.
