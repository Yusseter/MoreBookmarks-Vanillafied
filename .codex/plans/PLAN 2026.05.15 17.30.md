## Uygulama Değişiklikleri
- `map_data/definition.csv`:
  - `143` yeni MPE satırı TECH placeholder ID’lerine yazılacak.
  - Format: `new_id;r;g;b;Name, MPE_oldid;x;`
  - `12787/12788` korunacak, tekrar yazılmayacak.
  - Aynı RGB target’ta varsa önce semantic kontrol yapılacak; aynı şey değilse import durdurulup rapora düşecek.

- `common/landed_titles/00_landed_titles.txt`:
  - MPE `common/landed_titles/00_landed_titles.txt` içinden ilgili `b_*` blokları alınacak.
  - Source county target’ta varsa barony block’u o county içine eklenecek.
  - `province = old_mpe_id` değerleri target ID’ye çevrilecek.
  - Var olan `b_*` tekrar eklenmeyecek; province uyuşmazlığı varsa conflict raporu üretilecek.
  - Bloklara `# Yusseter: MPE_<old_id>` notu eklenecek.

- `common/province_terrain/00_province_terrain.txt`:
  - MPE `zz_MPE_province_terrain.txt` içindeki ilgili terrain satırları target ID’ye çevrilerek eklenecek.
  - Target ID için mevcut terrain varsa aynı mı kontrol edilecek; farklıysa otomatik ezilmeyecek, raporlanacak.

- `gfx/map/map_object_data/*.txt`:
  - MPE’de kullanılan ilgili locator/object block’ları 6 target dosyasına taşınacak:
    - `activities.txt`
    - `building_locators.txt`
    - `combat_locators.txt`
    - `player_stack_locators.txt`
    - `siege_locators.txt`
    - `special_building_locators.txt`
  - `id=old_mpe_id` target ID’ye çevrilecek.
  - Target block zaten varsa tekrar eklenmeyecek; farklı içerik varsa raporlanacak.

- `map_data/default.map`:
  - Gerçek province’e çevrilen TECH placeholder ID’leri placeholder bloğundan çıkarılacak.
  - Dış kategorilerde beklenmeyen membership varsa otomatik silinmeyecek; raporlanacak.
  - `provinces.png` bu turda değişmeyecek.

## Raporlar ve Kontroller
Yeni rapor klasörü:
`works/analysis/generated/mpe_import_add_1/`

Üretilecek ana raporlar:
- `mpe_rgb_inventory.csv`: overlay RGB -> MPE definition eşleşmesi.
- `mpe_import_id_map.csv`: `old_mpe_id -> target_id`.
- `mpe_existing_target_rgb_check.csv`: target’ta zaten olan RGB’lerin aynı şeyi temsil edip etmediği.
- `mpe_definition_changes.csv`: yazılan/korunan definition satırları.
- `mpe_landed_titles_import_report.csv`: eklenen, atlanan, conflict olan barony blokları.
- `mpe_province_terrain_import_report.csv`: terrain ekleme/uyuşmazlık durumu.
- `mpe_map_object_data_import_report.csv`: locator/object taşıma durumu.
- `mpe_default_map_placeholder_update_report.csv`: TECH placeholder çıkarımları.
- `mpe_unhandled_source_usages.csv`: MPE’de ilgili ID’lerin başka nerelerde geçtiği.

Doğrulama:
- `definition.csv` duplicate RGB kontrolü.
- `definition.csv` contiguous/id format kontrolü.
- `landed_titles` brace dengesi.
- Eklenen barony `province = id` değerleri target definition içinde var mı kontrolü.
- `default.map` içinde gerçek MPE ID’lerin artık TECH placeholder bloğunda kalmadığı kontrolü.
- `provinces.png` ve `test_files` dosyalarına dokunulmadığı kontrolü.
- `hafiza.md` içine sonuç ve yeni kuralların kısa kaydı.
