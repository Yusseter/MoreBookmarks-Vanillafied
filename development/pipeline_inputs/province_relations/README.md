# Province Relation Baseline

`province_relation_baseline.csv`, province geometrisi ve kimlik eşlemesi için makine üretimli canonical karşılaştırma snapshot'ıdır. Kullanıcı tarafından elle düzenlenen bir tablo değildir.

Current-state adayları `analysis/generated/province_relation_mapping/` altında üretilir. Yeni bir sonuç doğrulanmadan bu baseline'ın üzerine yazılmaz.
